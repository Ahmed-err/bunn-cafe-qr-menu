# Bunn & Hail — بُن وهيل

QR menu for a fictional Cairo specialty café: Arabic and English, search, loyalty card, and an owner panel to change prices and mark items sold out.

**Live demo:** https://sarmadax.com/work/bunn/

## Features
- Menu in Arabic and English, switchable in one tap
- Search and a sticky category bar
- Owner panel (`admin.html`) to edit prices and mark items sold out; the menu updates instantly
- Loyalty card section
- In this demo, owner edits are saved in the browser on that device only

## Stack
HTML5, CSS, vanilla JavaScript, inline SVG. Menu content lives in `data.js`.

## Run locally
No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
